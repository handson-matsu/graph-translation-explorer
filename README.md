# グラフの平行移動ラボ

同じ x を元の式と移動後の式に代入し、数表とグラフを比較する日本語教材。HTML・CSS・JavaScript・SVGのみで動作し、外部ライブラリ・ビルドは不要です。

## 実行

`index.html` をブラウザで開くか、`python3 -m http.server 8000` で配信して http://localhost:8000 を開いてください。GitHub Pagesはブランチのルートを公開元にできます。

## 操作

- 一次関数 y=ax+b／二次関数 y=ax²、係数・p・qを変更できます。
- 数表は x、f(x)、x−p、f(x−p)+q の4列です。行を選択すると (x,f(x)) と (x,f(x−p)+q) を同じ x 座標上で比較します。
- 初期範囲は−2〜2の1刻み5行。0.5刻み、最小・最大の変更に対応します。範囲は−10〜10、端点は0.5刻み。値は最小から指定間隔で生成し、最大を超えません。
- 「移動を追う点の x」は数表の選択とは独立しています。「点の移動を見る」で (a,f(a)) → (a+p,f(a)+q) を追跡します。終了後は終点を保持し、行選択または「同じ x で比較」で比較表示に戻ります。
- リセットで全設定と5行表示に戻ります。
